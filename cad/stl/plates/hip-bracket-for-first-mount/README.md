corrected to 28.4 mm). On that mount the servo hangs 1.7 mm higher, so this bracket's lower arm sits
1.7 mm lower (built with `BENCH_DROP = 1.7` in `cad/fusion/02_leg.py`). Use the normal
`print1-hip` plate for any new bench mount.
