# Build log #0: Hello, Rocky

*2026-11-23*

## What this is

Rocky Walker is a five-legged walking robot inspired by Rocky from *Project Hail Mary*, built in the open from the first commit. Everything I've built before has been private, so this time the whole process is public: the decisions, the maths, and the failures.

## Decisions so far

The full reasoning is in the [design doc](../design/2026-11-23-rocky-walker-design.md). The short version:

- **Five legs, radially symmetric, no front.** Rocky should walk in any direction and turn in place, not be a hexapod with a leg missing.
- **Raspberry Pi 5 + PCA9685 + 15 × MG996R.** One Python codebase. The PCA9685 generates servo pulses in hardware, so Linux timing jitter never reaches the servos.
- **Cheap enough to rebuild:** about $200 in parts plus a Pi. Every part fits a 180 mm print bed.
- **Parametric CAD in build123d.** One config file drives the CAD, the simulation and the kinematics.
- **Simulate before printing.** MuJoCo checks whether cheap servos can actually carry the robot before I print a single leg. If they can't, Rocky gets smaller, not more expensive.
